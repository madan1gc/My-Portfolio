# Reference style guide — Nichol & Mikon

Notes captured from live screenshots of two portfolio sites the user likes,
for design inspiration. Approximate colors read off screenshots, not exact
brand hexes. Reference only — see the redesign spec for what's actually
being applied.

## Nichol (nichol-vuejs.vercel.app)

**Palette:** dark navy base (#0A0B13), card panel (#14151F), primary violet
(#7C3AED), footer violet (#8B5CF6, brighter — used as a full-bleed wavy
footer curve), amber accent (#FBBF24).

**Type:** bold geometric sans (~Poppins/Manrope, 700–800) for headings;
Inter-like regular body copy, generous line-height.

**Signature patterns:**
- Pill-shaped eyebrow tag with a small icon above every section title
  ("+ SERVICES")
- Dashed circular motion lines orbiting the hero/CTA illustration
- Bold 3D-clay geometric icons (cube, pentagon), one per service card
- Full-bleed wavy violet curve breaking the footer — the one loud color
  moment on the page

## Mikon (Angular template, uiocean.com/angular/mikon)

**Palette:** pure black base (#0A0A0A), card black (#141414), signature
lime (#C6FF00), pale cream highlight (#F3EFC4), white text.

**Type:** bold rounded geometric sans, huge scale, low weight-contrast
(~Manrope) for the hero headline; one editorial italic serif heading
(~Playfair Display) used exactly once for contrast; all-caps letter-spaced
nav with a simple underline on the active link.

**Signature patterns:**
- Hero splits into two hard-edged blocks: black text side, solid-lime
  photo side — no gradient, one hard color break
- Role text types itself out with a blinking cursor in a pale-cream
  highlight box
- Stat numbers pair a bold figure with a lime "+"
- Project cards use a dark glass overlay on hover (title, tag pill,
  "View Project →")

## What NOT to copy directly

- The current site's own indigo→purple gradient blur/glow hero and
  bg-clip-text gradient headlines are a well-known "generic AI landing
  page" trope — moving away from it is the point of the current redesign,
  not something to reinforce by copying either reference's gradients.
- Nichol's stock 3D-clay illustration figures read as templated stock art.
- Mikon's lime-on-black/lime-on-white combinations need a contrast check
  before reuse at body-text sizes.
